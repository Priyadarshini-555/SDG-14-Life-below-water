# SDG-14-Life-below-water
# Grade 12 Project CBSE
# 🌊 SDG 14 Awareness & Action Tracker GUI

## 📖 Preface
This project is a Python-based GUI application designed to promote awareness of **Sustainable Development Goal 14 (Life Below Water)**.  
It combines **education, interactivity, and personal action tracking** to encourage sustainable practices and ocean conservation.

The application is suitable for students, educators, and environmental advocates who want an engaging way to learn and act on SDG 14.

---

## 📝 Project Description
The application provides:
- **Action Tracker**:  
  - Log daily sustainable actions (e.g., plastic reduction, waste segregation, community clean-ups).  
  - Store actions in a CSV file (`actions.csv`).  
  - Export actions to a new CSV file for reporting or sharing.  
  - View actions in a tabular format with scrollable interface.  

- **Quiz Module**:  
  - Interactive multiple-choice quiz on SDG 14.  
  - Instant feedback on answers.  
  - Certificate of Awareness generated for scores ≥ 70%.  

- **Charts Module** *(optional)*:  
  - Visualize logged actions over time using Matplotlib.  
  - Refresh charts dynamically to track impact.  
  - Provides insights into categories of sustainable actions.  

This project demonstrates how Python can be used to build **educational tools with real-world impact tracking**.
